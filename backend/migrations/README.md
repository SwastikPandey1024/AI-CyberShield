# Database Migrations

This directory contains Alembic database migration scripts for the AI CyberShield project.

## Structure

```
migrations/
├── versions/       # Individual migration scripts (auto-generated by Alembic)
├── README.md       # This file
└── .gitkeep        # Ensures directory is tracked
```

## Usage

```bash
# Create a new migration
alembic revision --autogenerate -m "description of changes"

# Apply all pending migrations
alembic upgrade head

# Rollback one migration
alembic downgrade -1

# View migration history
alembic history
```

## Guidelines

- Always review auto-generated migration scripts before applying.
- Test migrations on a development database before production.
- Never modify a migration that has already been applied to production.
- Create separate migrations for schema changes versus data migrations.
